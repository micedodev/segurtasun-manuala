# Iturriak

> Datu bakoitza nondik dator: dokumentuak, kasuak eta kodea.

Eskuliburu hau jatorrizko eduki didaktikoa da, baina gaia ez du asmatzen: unitate bakoitza dokumentazio publikoan oinarritzen da eta benetako kasu bakoitzak gertakari dokumentatuetara jotzen du. Adibideetako enpresak, berriz, fikziozkoak dira.

---

## Dokumentuak eta erreferentziak atalka

- **1UD · Sarrera**: [OWASP Top 10](https://owasp.org/www-project-top-ten/) phishing, bitartekari eta weberako; [NIST SP 800-63](https://pages.nist.gov/800-63-3/) autentikaziorako; [INCIBE](https://www.incibe.es/) phishing eta ransomware-rako.
- **2UD · Segurtasun logikoa**: [MITRE ATT&CK](https://attack.mitre.org/) botnet, agindu-kontrol eta alboko mugimendurako; [INCIBE](https://www.incibe.es/) eta [CCN-CERT](https://www.ccn-cert.cni.es/) ukapen eta sendotzerako.
- **3UD · Segurtasun aktiboa**: [MITRE ATT&CK](https://attack.mitre.org/) iraunkortasun, memoria eta saihespenerako; txosten publikoak har, RAT eta polimorfikoari buruz.
- **Segurtasun perimetrala**: [NIST CSF 2.0](https://www.nist.gov/cyberframework), [INCIBE](https://www.incibe.es/) eta [CCN-CERT](https://www.ccn-cert.cni.es/) suebaki, VPN, DMZ eta proxyrako.
- **Mamuak (drive-by download, 3UD)**: INCIBE eta OWASP deskarga iragankor eta exploit kit-ei buruz; fluxua web → script → Hop Point → ustiapen → malware.

---

## Benetako kasuak

- **WannaCry (2017)**: MS17-010 (2017-03-14); Europol (maiatzaren 12ko olatua); NHS osasun-eraginari buruz.
- **Sony Pictures (2014)**: FBIren atribuzioa (2014ko abendua); exfiltrazio, ezabatze eta iragazketei buruzkoa.
