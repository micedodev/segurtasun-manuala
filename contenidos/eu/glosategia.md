# Glosategi elebiduna

Eskuliburuko termino guztiak, beste hizkuntzako baliokidearekin eta garatzen diren fitxarako estekarekin.

| Terminoa | Gaztelaniaz | Atala | Definizioa |
| --- | --- | --- | --- |
| **Agindu eta kontrola** | Mando y control | 2UD · Segurtasun logikoa | Instalatutako malwareari aginduak bidali eta datuak jasotzeko azpiegitura. |
| **Alboko mugimendua** | Movimiento lateral | 1UD · Segurtasunaren sarrera | Ekipo batetik sareko besteetara hedatzea, kredentzialak berrerabiliz. |
| **Backdoor** | Backdoor | 1UD · Segurtasunaren sarrera | Autentikazio-kontrolak saihestuz sartzeko mekanismoa. |
| **Biren erasoa** | Ataque de intermediario | 1UD · Segurtasunaren sarrera | Erdiko gizonaren erasoaren euskal izena (Man-in-the-Middle). |
| **Botnet** | Botnet | 2UD · Segurtasun logikoa | Operadore berak kontrolatutako ekipo kutsatuen multzo koordinatua. |
| **DDoS** | DDoS | 2UD · Segurtasun logikoa | Baliabide finitu bat agortzea erabiltzaile legitimoak kanpo uzteko. |
| **DMZ** | DMZ | Segurtasun perimetrala | Kanpoko zerbitzuetarako sare-segmentu isolatua, Internetetik eta barrutik bereizia. |
| **Eraso-azalera** | Superficie de ataque | 2UD · Segurtasun logikoa | Eraso-puntuak: zerbitzuak, kontuak, baimenak eta softwarea. |
| **Man-in-the-Middle (MITM)** | Man-in-the-Middle (MITM) | 1UD · Segurtasunaren sarrera | Komunikazioa bitartean atzeman, irakurri eta aldatzeko erasoa. |
| **Erregistro zentralizatua** | Registro centralizado | 3UD · Segurtasun aktiboa | Ekipo guztien erregistroak denbora errealean bildu eta kanpoan gordetzen ditu. |
| **Estortsio bikoitza** | Doble extorsión | 1UD · Segurtasunaren sarrera | Datuak zifratu eta argitaratzearekin mehatxatzen du; kopia ez da nahikoa. |
| **Exfiltrazioa** | Exfiltración | 1UD · Segurtasunaren sarrera | Informazioa baimenik gabe ateratzea, trafiko legitimoan kamuflatuta. |
| **Exploit** | Exploit | 1UD · Segurtasunaren sarrera | Ahultasun bat aprobetxatuz programaren portaera aldatzeko kodea. |
| **Faktore anitzeko autentikazioa** | Autenticación multifactor | 1UD · Segurtasunaren sarrera | Bi froga kategoria desberdinetakoak: dakiguna, daukaguna eta garena. |
| **Ghostware** | Ghostware | 3UD · Segurtasun aktiboa | Helburua bete ondoren arrastorik uzten ez duen malwarea. |
| **Gutxieneko pribilegioaren printzipioa** | Principio de mínimo privilegio | Segurtasun perimetrala | Kontu eta prozesu bakoitzari zorrozki beharrezko baimenak soilik. |
| **Brute Force** | Ataque de fuerza bruta | 2UD · Segurtasun logikoa | Kredentzial bat konbinazioak probatuz asmatzeko saiakera sistematikoa. |
| **Ingeniaritza soziala** | Ingeniería social | 1UD · Segurtasunaren sarrera | Akats teknikoen ordez pertsonak manipulatzen dituen teknikak. |
| **Koobface** | Koobface | 2UD · Segurtasun logikoa | 2008ko harra Facebook eta MySpacen; botneta banku-kredentzialak lapurtzeko. |
| **Mamuak** | Descarga al paso (drive-by download) | 3UD · Segurtasun aktiboa | Kutsatutako webak bisitaria automatikoki infektatzen du, klikik gabe. |
| **Polymorphic Malware** | Malware polimórfico | 3UD · Segurtasun aktiboa | Kutsatze bakoitzean kodea aldatzen du sinadurak saihesteko. |
| **Phishing** | Phishing | 1UD · Segurtasunaren sarrera | Konfiantzazko itxura hartuz kredentzialak edo dirua eskuratzeko teknika. |
| **Proxy** | Proxy | Segurtasun perimetrala | Bezeroaren izenean eskaerak egiten dituen zerbitzaria. |
| **Ransomware** | Ransomware | 1UD · Segurtasunaren sarrera | Datuak zifratu (normalean atera ondoren) eta ordainketa eskatzen du. |
| **RAT** | RAT | 3UD · Segurtasun aktiboa | Kutsatutako ekipoaren urruneko kontrol interaktiboa denbora errealean. |
| **Rootkit** | Rootkit | 2UD · Segurtasun logikoa | Sarbideari eusteko eta presentzia ezkutatzeko tresnak, pribilegio handiekin. |
| **Social Worm** | Gusano de redes sociales | 2UD · Segurtasun logikoa | Sare sozial eta mezularitzatik zabaltzen den kodea, kontu konprometituetatik. |
| **Sarearen segmentazioa** | Segmentación de red | 2UD · Segurtasun logikoa | Sarea eremu iragaziekin banatzea, hedatzea mugatzeko. |
| **Worm** | Worm | 3UD · Segurtasun aktiboa | Bere kabuz hedatzen den malwarea, giza esku-hartzerik gabe. |
| **Sendotzea** | Bastionado | Segurtasun perimetrala | Agerpena murriztea: erabili gabekoa desaktibatu eta konfigurazioa gogortu. |
| **Spyware** | Spyware | 1UD · Segurtasunaren sarrera | Jarduera bildu eta hirugarrenei baimenik gabe bidaltzen dien softwarea. |
| **Stealer** | Stealer | 1UD · Segurtasunaren sarrera | Ekipoan gordetako sekretuak (pasahitzak, cookieak, tokenak) ateratzen ditu. |
| **Firewall** | Firewall | Segurtasun perimetrala | Sareen arteko trafikoa arau ordenatuekin kontrolatzen du: baimendu, errefusatu edo baztertu. |
| **Trojan** | Troyano | 1UD · Segurtasunaren sarrera | Itxuraz erabilgarria, ezkutuko karga maltzurrarekin. |
| **VPN** | VPN | Segurtasun perimetrala | Sare ez-fidagarriaren gainean kanal zifratu eta autentikatua sortzen du. |
| **Zero eguneko ahultasuna** | Vulnerabilidad de día cero | 3UD · Segurtasun aktiboa | Fabrikatzaileak zuzenketa argitaratu aurretik ustiatutako akatsa. |
