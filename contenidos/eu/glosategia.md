# Glosategi elebiduna

Eskuliburuko termino guztiak, beste hizkuntzako baliokidearekin eta garatzen diren fitxarako estekarekin.

| Terminoa | Gaztelaniaz | Atala | Definizioa |
| --- | --- | --- | --- |
| **Agindu eta kontrola** | Mando y control | 2UD · Segurtasun logikoa | Erasotzaileak dagoeneko instalatutako malwareari aginduak bidaltzeko eta honek itzultzen dizkion datuak jasotzeko erabiltzen duen azpiegitura. |
| **Alboko mugimendua** | Movimiento lateral | 1UD · Segurtasunaren sarrera | Erasotzailea sartu zen ekipotik sare bereko beste sistema batzuetara lekualdatzea, normalean kredentzialak berrerabiliz. |
| **Backdoor** | Backdoor | 1UD · Segurtasunaren sarrera | Aurreikusitako autentikazio-kontrolak saihestuz sistema batean sartzeko bidea ematen duen mekanismoa. |
| **Botnet** | Botnet | 2UD · Segurtasun logikoa | Operadore beraren urruneko kontrolpean geratu eta aginduak modu koordinatuan exekutatzen dituzten ekipo kutsatuen multzoa. |
| **DDoS** | DDoS | 2UD · Segurtasun logikoa | Helburuaren baliabide finitu bat agortu nahi duen erasoa —banda-zabalera, aldi bereko konexioak, prozesatzeko ahalmena edo memoria— erabiltzaile legitimoak artatzeari utz diezaion. |
| **DMZ** | DMZ | Segurtasun perimetrala | Kanpotik eskuragarri egon behar duten zerbitzuak kokatzen diren sare-segmentu isolatua, Internetetik eta barne saretik iragazketa-arauen bidez bereizia. |
| **Eraso-azalera** | Superficie de ataque | 2UD · Segurtasun logikoa | Sistema bat erasotzeko erabil daitezkeen puntu guztien multzoa: agerian dauden zerbitzuak, kontuak, baimenak eta instalatutako softwarea. |
| **Man-in-the-Middle (MITM)** | Man-in-the-Middle (MITM) | 1UD · Segurtasunaren sarrera | Hirugarren bat komunikazio baten bidean kokatu eta hura birbidaltzen duen erasoa; bide horretan irakurri eta alda dezake, ez igorleak ez hartzaileak nabaritu gabe. |
| **Erregistro zentralizatua** | Registro centralizado | 3UD · Segurtasun aktiboa | Ekipo guztien erregistroak denbora errealean biltzen dituen eta sortu dituenaren eskumenetik kanpo gordetzen dituen sistema. |
| **Estortsio bikoitza** | Doble extorsión | 1UD · Segurtasunaren sarrera | Datuak zifratzeaz gain argitaratzeko mehatxua egiten duen ransomware eredua; beraz, kopia bat leheneratzeak ez du gertakaria ixten. |
| **Exfiltrazioa** | Exfiltración | 1UD · Segurtasunaren sarrera | Informazioa erakundetik kanpora baimenik gabe ateratzea, normalean itxura legitimoa duen trafikoaren barruan kamuflatuta. |
| **Exploit** | Exploit | 1UD · Segurtasunaren sarrera | Programa baten ahultasun jakin bat aprobetxatzeko eta hark aurreikusi gabeko moduan joka dezan lortzeko diseinatutako kode zati edo datu segida: erasotzailearen aginduak exekutatzea,… |
| **Faktore anitzeko autentikazioa** | Autenticación multifactor | 1UD · Segurtasunaren sarrera | Kategoria desberdineko gutxienez bi froga eskatzen dituen nortasun-egiaztapena: dakiguna, daukaguna eta garena. |
| **Ghostware** | Ghostware | 3UD · Segurtasun aktiboa | Bere helburua bete ondoren existitu izanaren frogarik gera ez dadin diseinatutako malwarea. |
| **Gutxieneko pribilegioaren printzipioa** | Principio de mínimo privilegio | Segurtasun perimetrala | Kontu eta prozesu bakoitzak bere funtziorako zorrozki beharrezkoak diren baimenak bakarrik izan behar dituela dioen araua. |
| **Brute Force** | Brute Force | 2UD · Segurtasun logikoa | Kredentzial bat asmatzeko saiakera sistematikoa, konbinazioak probatuz asmatu arte. |
| **Ingeniaritza soziala** | Ingeniería social | 1UD · Segurtasunaren sarrera | Pertsona bat ekintza bat egitera edo informazioa ematera bultzatzeko teknika multzoa, sistemaren akats tekniko bat erasotu beharrean. |
| **Polymorphic Malware** | Malware polimórfico | 3UD · Segurtasun aktiboa | Kutsatze edo exekuzio bakoitzean bere kodea aldatzen duen malwarea; ondorioz, fitxategia inoiz ez da berdina eta haren edukian oinarritutako sinadura batek ere ez du bi aldiz ezagutzen. |
| **Phishing** | Phishing | 1UD · Segurtasunaren sarrera | Ingeniaritza sozialeko teknika, non erasotzaileak konfiantzazko erakunde baten itxura hartzen duen biktimak kredentzialak, datu pertsonalak edo dirua eman ditzan, edo fitxategi bat exekuta… |
| **Proxy** | Proxy | Segurtasun perimetrala | Bezeroaren eta helmugaren artean kokatu eta eskaera haren izenean egiten duen zerbitzaria. |
| **Ransomware** | Ransomware | 1UD · Segurtasunaren sarrera | Biktimaren datuak zifratzen dituen —eta normalean aurretik ateratzen dituen— malwarea, deszifratze-gakoaren eta datuak ez argitaratzeko konpromisoaren truke ordainketa bat eskatzeko. |
| **RAT** | RAT | 3UD · Segurtasun aktiboa | Erasotzaileari kutsatutako ekipoaren gaineko kontrol interaktiboa eta denbora errealean ematen duena: fitxategi-sistema, kamera, mikrofonoa, teklatua, pantaila eta sarea. |
| **Rootkit** | Rootkit | 2UD · Segurtasun logikoa | Pribilegio handiekin instalatzen den tresna multzoa, sistema baterako sarbideari eusteko eta, batez ere, bere presentzia eta beste osagai maltzur batzuena ezkutatzeko. |
| **Social Worm** | Social Worm | 2UD · Segurtasun logikoa | Plataforma sozialen eta mezularitzaren bidez zabaltzen den kode maltzurra, dagoeneko arriskuan dauden kontuak erabiliz haien kontaktuetara iristeko. |
| **Sarearen segmentazioa** | Segmentación de red | 2UD · Segurtasun logikoa | Sarea eremutan banatzea haien artean iragazketarekin, arriskuan dagoen ekipo batek gainerako guztietara iritsi ezin dezan. |
| **Worm** | Worm | 3UD · Segurtasun aktiboa | Bere kabuz ugaldu eta sistema batetik bestera hedatzeko gai den malwarea, giza esku-hartzerik gabe, sarean eskuragarri dauden zerbitzuen ahultasunak edo baliozko kredentzialak aprobetxatuz. |
| **Sendotzea** | Bastionado | Segurtasun perimetrala | Sistema baten agerpena murrizteko prozesua: erabiltzen ez dena desaktibatu, zerbitzuak itxi eta konfigurazioa gogortu. |
| **Spyware** | Spyware | 1UD · Segurtasunaren sarrera | Sistema baten edo bere erabiltzailearen jarduerari buruzko informazioa biltzen duen eta hirugarren bati baimen informaturik gabe helarazten dion softwarea. |
| **Stealer** | Stealer | 1UD · Segurtasunaren sarrera | Ekipo batean gordetako sekretuak —nabigatzailean gordetako pasahitzak, saioko cookieak, aplikazioen tokenak eta konfigurazio-fitxategiak— aurkitu eta ateratzen espezializatutako malwarea,… |
| **Firewall** | Firewall | Segurtasun perimetrala | Bi sareren arteko trafikoa kontrolatzen duen sistema, arau multzo ordenatu bat aplikatuz: pakete edo konexio bakoitzeko, baimendu, abisuarekin errefusatu edo isilean baztertu behar den… |
| **Trojan** | Troyano | 1UD · Segurtasunaren sarrera | Itxuraz erabilgarria den funtzionalitate bat eskaintzen duen programa, ezkutuan karga maltzur bat ere exekutatzen duena. |
| **VPN** | VPN | Segurtasun perimetrala | Konfiantzazkoa ez den sare baten bidez bi muturren artean kanal zifratu eta autentikatu bat sortzen duen teknologia, hortik igarotzen den trafikoa atzematen duenarentzat irakurtezina eta… |
| **Zero eguneko ahultasuna** | Vulnerabilidad de día cero | 3UD · Segurtasun aktiboa | Erasotzaile batek fabrikatzaileak zuzenketa argitaratu aurretik aprobetxatzen duen segurtasun-akatsa. |
