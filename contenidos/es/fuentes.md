# Fuentes

> De dónde sale cada dato: documentos, casos y código.

Este manual es contenido didáctico original, pero no inventa la materia: cada unidad se apoya en documentación pública y cada caso real remite a hechos documentados. Las empresas de los casos ilustrativos, en cambio, son ficticias.

---

## Documentos y referencias por unidad

- **UD1 · Introducción**: [OWASP Top 10](https://owasp.org/www-project-top-ten/) para phishing, intermediario y web; [NIST SP 800-63](https://pages.nist.gov/800-63-3/) para autenticación; [INCIBE](https://www.incibe.es/) para phishing y ransomware.
- **UD2 · Seguridad lógica**: [MITRE ATT&CK](https://attack.mitre.org/) para botnets, mando y control y lateral; [INCIBE](https://www.incibe.es/) y [CCN-CERT](https://www.ccn-cert.cni.es/) para DoS y bastionado.
- **UD3 · Seguridad activa**: [MITRE ATT&CK](https://attack.mitre.org/) para persistencia, memoria y evasión; informes públicos sobre gusano, RAT y polimórfico.
- **Seguridad perimetral**: [NIST CSF 2.0](https://www.nist.gov/cyberframework), [INCIBE](https://www.incibe.es/) y [CCN-CERT](https://www.ccn-cert.cni.es/) para cortafuegos, VPN, DMZ y proxy.
- **Mamuak (drive-by download, UD3)**: INCIBE y OWASP sobre descargas al paso y exploit kits; flujo web → script → Hop Point → exploit → malware.

## Casos reales

- **WannaCry (2017)**: MS17-010 (14-03-2017); Europol (oleada del 12 de mayo); NHS sobre impacto sanitario.
- **Sony Pictures (2014)**: atribución del FBI (diciembre de 2014); exfiltración, borrado y filtraciones de noviembre y diciembre.
